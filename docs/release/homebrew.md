# Homebrew Scaffold

Pump's Homebrew path should be generated by `cargo-dist`.

The `Cargo.toml` `workspace.metadata.dist` block configures:

- shell installer generation,
- Homebrew installer generation,
- release targets for macOS, Linux, and Windows,
- a formula named `pump`.

## Local Preview

```sh
dist plan
dist build
```

Inspect `target/distrib/` after a local build. Do not push tap changes or run
release workflows until the project is intentionally ready for publishing.

## Tap Policy To Settle Later

- exact tap repository and visibility,
- whether tap updates are committed directly or opened as PRs,
- token/secret name for tap writes,
- whether release assets are downloaded directly from GitHub Releases or
  mirrored through another artifact endpoint.

Until then, treat Homebrew as configured-but-held packaging.
